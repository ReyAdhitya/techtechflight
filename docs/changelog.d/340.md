- **Attendance over time.** Present and absent counts per Student, sealed from the marks the Teacher already keeps.

DECISION: Attendance history lives in a side localStorage key (`techtechflight:attendance-history`), not inside the Logbook shape. Parallel wave tickets cannot extend `Logbook` without colliding. The Integrator should call `sealAttendanceFromBook(lessonId, book, at)` when a Lesson closes so the open `absentStudentIds` marks become a lasting session. Counts stay at zero until something is sealed — inventing absence from "not assigned" would misread rotations as truancy.
